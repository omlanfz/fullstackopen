# Full Stack Open — University of Helsinki

This repository contains my submissions and solutions for [Full Stack Open](https://fullstackopen.com/en/), an advanced web development course provided by the **University of Helsinki**.

## 📌 Overview

The course covers modern full-stack web development using **React**, **Redux**, **Node.js**, **Express**, and **MongoDB**, focusing on building scalable, production-ready applications with RESTful APIs and modern frontend state management.

- **Institution:** University of Helsinki (Open University)
- **Primary Stack:** JavaScript (ES6+), React, Node.js, Express, MongoDB
- **Tools Used:** VS Code, Git, GitHub
